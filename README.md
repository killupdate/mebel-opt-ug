# ОПТ МЕБЕЛЬ ЮГ

Адаптивная основа сайта контрактного производства мебели с Three.js scroll-анимацией шкафа.

## Запуск

Раздавайте папку `dist` через HTTP-сервер. Например: `python3 -m http.server 4173 --directory dist`.
Сборка не требуется. Открытие index.html через file:// не подходит для ES-модулей.

## Публикация

Статический корень — `dist/`. Основной домен — `mebel-opt-ug.ru`; DNS подключается после выбора хостинга. `.openai/hosting.json` содержит идентификатор приватного предпросмотра Sites. Это не настройка DNS.

## Редактирование

`dist/index.html` — структура и контакты; `dist/style.css` — адаптивная вёрстка; `dist/app.js` — анимация и подготовка запроса. `dist/assets/three.*.js` — Three.js 0.180.0 (MIT).

Форма готовит текст для копирования или почтового клиента и ничего не отправляет автоматически. Модель шкафа демонстрационная. Реальные фото производства и товарные карточки нужно добавлять на основе утверждённых материалов.

## Сквозная scroll-сцена

Все разделы в `#story` используют один `#scene` с фиксированным WebGL canvas. Массив `poses` в app.js соответствует девяти `.chapter` в HTML. Прогресс вычисляется из текущей позиции обычного скролла и расположения разделов; рендер запускается через requestAnimationFrame по событию прокрутки/resize. Нет перехвата колеса, автоматического проигрывания или необратимых триггеров. Двери и ручки вращаются вокруг общих осей петель; разборка сохраняет два левых внутренних ящика.

Для добавления раздела нужно добавить соответствующую позу модели. Мобильный масштаб учитывает высоту текущего текстового блока. `prefers-reduced-motion` отключает плавные переходы. Подготовка письма и кнопки контактов сохранены.
